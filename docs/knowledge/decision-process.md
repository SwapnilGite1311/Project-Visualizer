# Decision process

Decisions are made and recorded the same way every time.

1. Write an ADR with status Proposed.
2. The other founder reviews it within 48 h.
3. Accept or reject it; set the status.
4. Add it to `docs/decisions/decision-log.md`.
5. If the plan must change, commit with the prefix `PLAN:` and re-run `scripts/plan/plan_lint.py`.
