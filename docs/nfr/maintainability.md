# Maintainability and extensibility

| ID | Goal |
|---|---|
| MNT-01 | Strict module boundaries (R3, R8). |
| MNT-02 | New language = new `lang_*` module or plugin, no core changes. |
| MNT-03 | New UI feature = new `features/<name>` folder, no shell changes. |
| MNT-04 | Engine core modules ≥ 70% line coverage. |
| MNT-05 | Every public RPC method has a JSON Schema and an example. |
| MNT-06 | Every architecture decision has an ADR. |
