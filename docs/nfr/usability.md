# Usability and accessibility

| ID | Target |
|---|---|
| USE-01 | From first launch to first map in < 2 minutes without reading docs. |
| USE-02 | Every AI text uses plain language (no unexplained jargon). |
| USE-03 | All actions reachable by keyboard; shortcuts listed in a help screen. |
| USE-04 | Colour is never the only signal (badges/icons too); WCAG 2.1 AA contrast. |
| USE-05 | Errors shown to users say what happened and what to do next. |
| USE-06 | Light and dark themes. |
