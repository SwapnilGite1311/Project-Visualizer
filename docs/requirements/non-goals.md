# MVP non-goals

- No languages other than Python.
- No 3D.
- No runtime overlay.
- No cloud accounts or servers.
- No team features.
- No statement-level view.
- No prediction or simulation.
- No VS Code extension.
- No billing.
- No installer auto-update.
- No editing code inside the app.

## Why

The MVP must prove one thing: that a clickable map plus Explain plus What breaks? is valuable for Python developers. Everything else waits for evidence.
