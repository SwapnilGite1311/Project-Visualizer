# MVP test session script (45 minutes)

## Before the call

- Send the installer link and ask the participant to have a Python project ready (their own, or one they recently had to understand).
- Prepare an AI key for them and a spare open-source project.
- Open `sessions-log.md` and start a new `## Session NN — <date> — <role>` section.

## Intro (3 minutes)

> Thanks for joining! Today you'll try a new app called Project Visualizer on your own code.
>
> We're testing the product, not you. If something is confusing or doesn't work, that's exactly what we need to find, so please be honest; you can't hurt our feelings.
>
> Please think out loud as you go: say what you're looking for, what you expect, and what surprises you. I'll mostly stay quiet and won't help unless you're really stuck.
>
> Is it OK if we record the screen and audio? The recording is only used by our team to improve the product and is deleted after the analysis.

Wait for a clear yes before recording.

## Warm-up (2 minutes)

1. What do you build, and which tools do you use to write code?
2. Tell me briefly about the project you brought: what does it do, and how well do you know it?

## Tasks (30 minutes)

Read each task exactly as written. Start a timer; stop it when they say they are done or after the time limit.

1. **Install (5 min):** "Please install the app from the link I sent and start it."
2. **Open (3 min):** "Open the project you brought in the app."
3. **Entry point (5 min):** "Using the app, find where this program starts running."
4. **Explain (5 min):** "Pick a function in your project that you find confusing, and use the app to understand what it does." (Give them the AI key when they reach the settings.)
5. **What breaks (5 min):** "Pick something you might want to change soon. Before changing it, find out with the app what else could break."
6. **Ratings (2 min):** "From 1 (useless) to 5 (I need this), how useful was: the map, Explain, What breaks?, Search, Insights?"

After each task: "How did that go? Anything confusing?"

## Follow-up questions (8 minutes)

- What confused you the most today?
- Was there a moment where the app saved you time? When?
- Did you trust the explanation and the "what breaks" list? Why or why not?
- What is missing that would make you use this every week?
- Would you pay for this? If yes, how much per month feels fair? (Let them name a number before suggesting any.)
- Who else do you know who should try this?

## Closing (2 minutes)

> That's everything, thank you! This was really helpful. You'll get <incentive> within 24 hours, and we'll let you know when the next version is out. Can we contact you again for a follow-up in a few weeks?

Stop the recording. Fill in the session section in `sessions-log.md` within 1 hour: task results (pass / fail and time), ratings, best quote, top problem, would pay.
