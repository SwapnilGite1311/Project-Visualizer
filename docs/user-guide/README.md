- [Exploring the map](exploring-the-map.md): levels, moving around, colors and shapes, focus mode, 2D and 3D.
- [Explain and What breaks?](explain-and-impact.md): AI explanations with citations, impact analysis, project notes.
- [Search and insights](search-and-insights.md): finding anything, hotspots, entry points, package boundaries.
- [Settings, privacy and AI keys](settings-and-privacy.md): providers, where keys live, what leaves your machine.
- [Troubleshooting](troubleshooting.md): common problems and where the logs are.
- [Keyboard shortcuts](keyboard-shortcuts.md): every shortcut in one table.
