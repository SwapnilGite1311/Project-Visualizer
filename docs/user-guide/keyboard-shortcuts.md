# Keyboard shortcuts

On macOS use `Cmd` instead of `Ctrl`. Every command, with or without a shortcut, is also in the command palette (`Ctrl+K`).

| Shortcut | Action |
| --- | --- |
| `Ctrl+O` | Open a folder |
| `Ctrl+K` | Command palette |
| `Ctrl+F` | Search |
| `Ctrl+E` | Explain the selected element |
| `Ctrl+0` | Fit the map to the screen |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+3` | Switch between 2D and 3D |
| `Alt+←` | Go back |
| `Alt+→` | Go forward |
| `Alt+↑` | Go up one level |
| `Alt+Home` | Go to the project overview |
| `Escape` | Clear the What breaks? highlight; close a dialog or menu |
| `Shift+Escape` | Clear focus mode |
