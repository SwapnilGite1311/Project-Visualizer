# User guide — new in Phase 3

Phase 3 brings the map to life: connect a running program and watch what it does, see which parts are healthy or failing, and find errors on the map.

- [Live runtime](live-runtime.md): connect a Python or Node.js program (or any OpenTelemetry app), read the live map, follow single requests and calls between modules, pause and replay.
- [Health and errors](health-and-errors.md): health colors, finding the root cause of a problem, pasting an error to see where it happened, the runtime errors list and the thresholds.
- [More languages](languages.md): C, C++, Rust and C#.
- Watching deployed apps and importing repositories in the cloud arrive with the cloud features (a page will be added then).

Everything in these pages runs on your own computer: the running program sends to the desktop app only, at `127.0.0.1`.
