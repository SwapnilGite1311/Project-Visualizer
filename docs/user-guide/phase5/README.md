# User guide — new in Phase 5

Phase 5 is about the future of your code: look back at how it got here, try a change before you make it, and see which parts are likely to fail or slow down.

- [Dashboards, simple words and help](dashboards-and-help.md): the dashboards on the left, everyday words for code terms, the guided tour, "How do I…" help and the sample project.
- [Time travel and simulation](time-travel-and-simulation.md): step through your Git history on the map, open a sandbox, simulate removing, slowing down or breaking parts, and read the comparison with reality.
- [Predictions, forecasts and decisions](predictions-and-decisions.md): failure predictions, bottlenecks, the 24-hour health forecast, the go / caution / no-go recommendation, how confident each number is and what is sent to the cloud.

Time travel, simulation, the local predictions and forecasts and the recommendation all run on your own computer. A trained prediction model and the cloud forecast are used only when you are signed in to the cloud (see the last section of the second page).
