# Roadmap

## Phase 0 — Setup and planning

- Repository, tools and status tracking.
- Requirements and non-functional requirements.
- Architecture, component designs and domain model.
- Contracts (JSON Schemas) and CI.

## Phase 1 — Core twin visualization

- Import a folder, parse Python, build the layered graph, show the 2D map.
- Navigate levels, explain any node with AI, see what breaks if it changes → **MVP checkpoint**.
- Then: search, insights, 3D, Git import, packaging.
- User testing with 15–20 users.

## Phase 2 — Interactivity and dependency navigation

- Interactivity and dependency navigation (forward, reverse, path, cycles).
- VS Code extension.
- JS/TS, Java and Go support.
- Cloud foundation: accounts, teams, snapshot sync.

## Phase 3 — Live runtime overlays and module tracing

- Live runtime overlays and module tracing.
- Health and error detection.
- C/C++, Rust and C# support.
- Runtime collector.

## Phase 4 — AI debugging and impact analysis

- AI error explanation and auto-fix sync.
- Change impact preview and contextual Q&A.
- MCP server and language plugins.

## Phase 5 — Prediction, simulation and what-if analysis

- Behaviour prediction and what-if simulation.
- Health forecasting and recommendations.
- Time-travel view.

## Phase 6 — Startup and business launch

- Business model, go-to-market, legal, funding, team, growth.
- Billing and enterprise features.
- YC application.

## MVP definition

Python projects only; import a folder; see a clickable 2D map; drill down through levels; get a plain-language explanation of any node; see what breaks if a node changes; everything runs locally.
