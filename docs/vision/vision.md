# Vision

## One sentence

A software digital twin: a live, explorable model of a codebase that lets developers see its architecture, watch it run, understand its errors in plain language, and simulate changes before making them.

## Vision

Make software visible.

## Mission

Build the software digital twin.

## Core principles

- One phase, one mission.
- One owner per capability.
- No overlap.
- The MVP emerges from the build.

## Product philosophy

- A living twin: always in sync with code and runtime.
- 2D/3D twinning.
- Zoom means moving down the abstraction stack, not moving a camera.

## Abstraction stack

1. Project
2. Packages
3. Modules (files)
4. Classes
5. Functions
6. Statements
7. Runtime flow
8. Simulation

## Who it is for

- Developers who build with AI and do not fully understand the result.
- Python, data and ML developers.
- Tech leads.
- Enterprise architects.
